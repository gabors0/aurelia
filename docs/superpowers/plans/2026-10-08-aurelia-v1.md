# Aurelia v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A cinematic GPUI Jellyfin desktop client (Movies & TV) that plays via mpv with resume/progress sync.

**Architecture:** Cargo workspace: `crates/jellyfin` (async API client), `crates/player` (Player trait + mpv IPC), `crates/aurelia` (GPUI app on gpui-component). Network on a Tokio runtime, UI on GPUI executors; images decoded/blurred off-thread into `RenderImage`s.

**Tech Stack:** Rust 2024, gpui-component 0.7.1, gpui-pre 0.3.8, gpui-pre-platform 0.3.8, reqwest (rustls), tokio, serde, image 0.25, blurhash, tracing, wiremock (tests), Nix flake.

**Spec:** `docs/superpowers/specs/2026-10-08-aurelia-design.md`

## Global Constraints

- Jellyfin API compatible with 10.9+ (user server 10.11.11, demo 12.2.0).
- Auth header: `MediaBrowser Client="Aurelia", Device="<hostname>", DeviceId="<uuid>", Version="<CARGO_PKG_VERSION>"`, plus `, Token="<token>"` when logged in.
- Token stored in `~/.config/aurelia/session.json` with mode 0600; password never persisted; token never on the mpv command line.
- Image cache: `~/.cache/aurelia/images/`.
- Default server pre-fill: `https://jellyfin.gs0.me`.
- Theme tokens: bg `#0A0B10`, glass white 6 %, border white 9 %, text `#F2F3F7` / `#A3A7B5` / `#6B7080`, accent fallback `#B69CFF`.
- Dev auto-login env: `AURELIA_SERVER`, `AURELIA_USER`, `AURELIA_PASSWORD` (empty allowed); `AURELIA_LOG` for tracing filter.
- Never create a git remote.

## Review Focus

1. Server URL typed as `jellyfin.gs0.me`, `https://host/`, or `https://host/web/index.html` → normalised to `https://host` (Task 2 test `normalizes_server_urls`).
2. Items missing images/metadata (no backdrop, logo, runtime, year, overview) → placeholders, never a panic (Task 2 fixture test `minimal_item_deserializes`; Task 6 uses `Option`s throughout).
3. Multiple audio tracks + external subtitles → correct mpv `aid`/`sid` mapping, "Off" respected (Task 4 test `maps_jellyfin_indices_to_mpv_ids`).
4. mpv exits before/without loading the file (missing binary, crash, user closes instantly) → `Ended` still emitted, `Stopped` still reported (Task 4 test `exit_without_file_loaded_emits_ended`; Task 11 reporter test `reports_stopped_on_early_exit`).
5. Token revoked mid-session (401) → session cleared, login shown with "Session expired" (Task 2 test `maps_401_to_unauthorized`; Task 8 handles `Error::Unauthorized`).
